每一次打开首页，我们都在交出一小部分生活：几分钟的闲暇，一次寻找答案的机会，一份尚未成形的好奇。这些时间值得被认真对待。

我们在此建造一个由用户可自主定义推荐方式的平台。在这里，人可以决定关注什么、屏蔽什么，以什么顺序接收信息，也可以随时修改

决定。技术应当帮助我们实现这些选择，并让选择真正生效。

**我们认为，每个人都是闲暇时光真正的主人。**

喜欢一类内容，不等于愿意被它包围。看过一次视频，不等于接受一个永久标签。今天的兴趣，也不应成为明天必须延续的习惯。昨天的 你喜欢二次元，不代表今天的你不能迷上古典哲学；这一刻你为游戏热血沸腾，下一秒你同样可以为一段乡村纪实热泪盈眶。算法总是试图用过去的数据定义你的未来，但在这里，你可以随时推翻自己的“人设”。你的每一次转向、每一次拓荒，都会得到最热烈的回应。

人有权探索，有权厌倦，有权改变。推荐算法应当为这种变化留出空间。我们要让“不感兴趣”能够被尊重，“不再推荐”能够被真正执行。用户可以看到自己熟悉的世界之外正在发生什么。

算法可以复杂，决定却应当接受追问。我们承认判断会出错。因此，我们要把解释、纠错和恢复放进产品最基本的设计之中。

有人需要完整的课程，有人喜欢热闹的直播；有人愿意追踪热点，有人只想安静地读完一篇文章。不同的信息生活可以共存。

我们可以分享过滤规则、白名单和屏蔽名单，也必须保留拒绝订阅、单独修改和随时退出的权利。共同维护的名单应当说明来源、依据与适用范围，并允许纠错。

没有一张名单能够替所有人定义价值。任何人的一次误判，都不应轻易成为另一个创作者无法摆脱的标签。一次集中投稿可能是一门课程，一段简短视频也可能记录着珍贵的经验。频率、时长、热度和粉丝数可以帮助筛选，却不应该完全决定内容的价值。

我们愿意让具体作品得到具体判断，让认真创作的人有机会遇见真正需要他们的读者与观众。我们尊重原创、署名和创作者对作品的权利，也尊重用户选择离开的自由。

**我们保证，注意力应当由用户自己支配。**

平台可以获得维持服务的收入，商业推广应当清楚标明。我们会用更长久的尺度衡量一个平台：用户是否找到了需要的信息，是否学会了想学的东西，是否在结束浏览时感到满足，是否能够安心关掉屏幕，回到自己的生活。

此平台允许用户带走订阅、规则和个人记录，允许用户质疑我们的决定，允许社区参与改进，也随时允许任何人根据自己的意愿加入或离开。我们虽然无法替所有人选出最好的内容，但愿意提供可靠的工具与平台，让每个人都能拥有一方净土。

我们将从一个小小的决定开始：让一次恢复确实恢复，让一次拒绝确实有效，让一份选择始终属于作出选择的人。

每一次打开，都出于自己的意愿。

每一次停留，都有自己认可的理由。

愿信息通向更晴朗的世界。
